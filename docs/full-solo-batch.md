## Batch tool

`python -m jazz_solo.full_solo_batch MANIFEST.json --output-dir OUTPUT` processes explicit, already-sourced local solo boundaries and writes a resumable results report, raw MIDI and reading-copy MusicXML. A manifest is a JSON array of objects with unique safe `id`, local `source`, `start` and `end` in seconds, and optional boolean `skip_separation`. The caller must determine the correct take and full solo boundaries; the tool does not verify them. It records failures, refuses to reuse an ID for different source metadata/bounds, preserves earlier results on conflict, and resumes completed identical jobs when expected outputs exist. The source file path, size and modification time are fingerprinted; changing model/configuration code does not invalidate the fingerprint, so use a fresh output ID for changed models. Progress reports and audio remain local.
